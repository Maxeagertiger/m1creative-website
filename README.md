# M1CREATIVE. — Premium Web Design & Creative Agency

A stunning, immersive agency website featuring:

- 🌌 **3D Three.js Scene** — Interactive space environment with stars, nebula, planet, and floating geometries
- 🎬 **GSAP Scroll Animations** — Smooth scroll-triggered reveals and parallax effects
- 📱 **Fully Responsive** — Optimized for all devices
- 📝 **Lead Capture Form** — Service selection pills, floating labels, and success animations
- ✨ **Premium Design** — Glassmorphism, gradient accents, custom cursor glow, and micro-animations

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- [Three.js](https://threejs.org/) — 3D WebGL rendering
- [GSAP](https://greensock.com/gsap/) — ScrollTrigger animations
- [Google Fonts](https://fonts.google.com/) — Inter + Permanent Marker

## Getting Started

Simply open `index.html` in your browser, or serve with any static file server.
